# Shiba Day

Shiba Day is an iOS app for organizing daily tasks and tracking personal goals. It includes interactive Home Screen widgets that let you complete tasks and update goal progress without opening the app.

## Features

- Create, edit, complete, and delete tasks
- Set recurring tasks and browse tasks by date
- Create, edit goals and track progress
- Receive local reminders for tasks and goals
- Use interactive widgets for tasks and goals
- Choose light, dark, or system appearance

## Built with

Swift, SwiftUI, SwiftData, WidgetKit, App Intents, and UserNotifications.
